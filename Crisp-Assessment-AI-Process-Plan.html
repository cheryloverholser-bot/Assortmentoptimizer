Crisp Assessment Process — AI-Enhanced

A living reference for running AI-assisted category management assessments. Each phase documents what the team does, where Claude helps, and what must be complete before moving forward.

Phase 1
Intake
Output: Baseline insight on people, process & tech
Phase 2
Discovery
Output: Workshop notes & current-state view
Phase 3
Analysis
Output: Prioritized opportunity log
Phase 4
Roadmap & Readout
Output: Solution roadmap & exec readout

How to use this site

Navigate by phaseUse the sidebar to move through the 4 phases in order. Don't skip a phase until its gate is cleared.
Use the AI stepsEach phase has AI steps — current (NOW) and new (NEW). Full prompts are in the AI Prompt Library.
Check the gatesEach phase ends with a gate. All criteria must be met before the next phase begins.

Phase 1 — Intake
Questionnaire Maturity Scorer
Phase 1 · NOW
▾
What to paste in
Completed CMS Questionnaire responses — paste cells as plain text if copying from Excel.
Prompt — click to copy
You are a category management maturity assessor for a CPG consulting firm. Review the following completed assessment questionnaire and: 1. Score the client's maturity across these dimensions: Data & Analytics, Process Maturity, Technology, Collaboration, Strategy. Use a 1–5 scale (1=basic, 5=best-in-class). 2. Flag any dimensions scoring 2 or below as priority gaps. 3. Identify the top 3 areas of strength. 4. Note any questions left blank or answered vaguely — flag as "incomplete inputs." Format: Maturity Scores (table) / Priority Gaps (bullets) / Strengths (bullets) / Incomplete Inputs (if any) Questionnaire responses: [PASTE QUESTIONNAIRE HERE]
If the questionnaire is in Excel, paste cells as plain text.
